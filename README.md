# Kawasaki Disease Diagnosis Using a Feature-Optimized Ensemble Model

**Kawasaki Disease Diagnosis Using a Feature-Optimized Ensemble Model** is a Python-based machine learning project designed to **assist in early detection of Kawasaki Disease in children**. The system uses **feature selection and ensemble learning** to improve prediction accuracy and support clinical decision-making.

---

## Features
- Feature-optimized preprocessing for higher prediction accuracy  
- Ensemble model combining multiple classifiers  
- Automated data cleaning and feature selection  
- Data visualization for insights

---

## Technologies Used
- Python  
- NumPy & Pandas  
- Scikit-learn  
- Matplotlib & Seaborn  
- Jupyter Notebook  

---

## Project Structure
- `main.py` – Runs the full model pipeline  
- `data_preprocessing.py` – Data cleaning and feature optimization  
- `ensemble_model.py` – Ensemble classifier implementation  
- `requirements.txt` – Required Python libraries  
- `README.md` – Project overview and instructions  
- `datasets/` – Input datasets (CSV files)
